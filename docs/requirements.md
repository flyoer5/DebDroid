# DebDroid v2 — 需求规格说明书（Requirements Specification）

> 版本：2.0.0-draft · 状态：已确认（2026-08-26）
> 本文档是重写版的唯一需求来源，贯穿 模拟页 → 代码 → 验收 全流程。
> 变更任何 FR 必须同步更新本文档、模拟页与验收清单，禁止出现第二套描述。

## 1. 产品概述

### 1.1 定位
**DebDroid 是在 Android 手机上免 root 运行完整 Debian 13 (trixie) 的终端 App。**
Debian rootfs 直接内置在 APK 中，首次使用零下载、完全离线；通过 proot 用户态实现，
无需解锁 bootloader、无需 root。

### 1.2 核心价值（一句话）
> 把手机变成一台随时可用的 Debian 开发机：终端 + 文件管理 + 编辑 + SSH，全部离线可用。

### 1.3 目标用户
- 开发者 / 极客：在手机上跑 Linux 工具链（apt / python / node / git）
- 服务器运维：通过内置 SSH 从电脑连入手机里的 Debian
- 学生 / 学习 Linux 的用户：零成本体验完整 Debian

### 1.4 与旧版（v1.x）的关系
v1.x 因补丁堆叠、架构反复、文档失修而混乱。v2 为**从零重写**：
代码全部重写、git 历史清空、单 arm64、工程化配置与测试门禁。
功能范围与 v1.x 对齐（终端/文件/编辑/SSH/保活全保留），但实现全部重构。

## 2. 术语表

| 术语 | 含义 |
|---|---|
| rootfs | Debian 13 根文件系统镜像（打包为 rootfs.tar.xz 内置 APK） |
| proot | 用户态 chroot 实现，免 root 运行 guest 系统（Termux 维护构建） |
| session | 一个终端会话 = 一个 proot 进程 + 一个 pty + 一个 TerminalSession |
| tmux attach | `tmux new -A -s main`，重开会话时回到原现场 |
| keep-alive | 前台服务 + 唤醒锁 + 电池白名单 + 开机自启的组合保活 |
| flavor/abi | 本版仅 arm64（arm64-v8a），不构建其他 ABI |

## 3. 技术约束与决策

| # | 决策 | 值 | 理由 |
|---|---|---|---|
| T-01 | 最低系统 | **minSdk 26** (Android 8.0) | 单 arm64 即现代设备；Compose 体验与构建简化 |
| T-02 | 目标系统 | **targetSdk 28** (硬约束) | API 29+ 禁止执行应用私有目录中的可执行文件，proot 无法运行（与 Termux 同因） |
| T-03 | 编译系统 | compileSdk 36 / AGP 8.13.2 / Kotlin 2.4.10 / Gradle 8.14.5 | 与 v1.x 已验证的工具链一致 |
| T-04 | ABI | **仅 arm64-v8a** | 现代手机全覆盖；rootfs/proot 资产体积最小化 |
| T-05 | UI 栈 | Kotlin + Jetpack Compose + Material3 | v1.x 已验证；声明式 UI 便于测试 |
| T-06 | 持久化 | DataStore Preferences | 轻量键值，支持 Flow 响应式 |
| T-07 | 异步 | Kotlin 协程 + StateFlow | 全部重活（解压/apt/SSH）后台执行，UI 不冻结 |
| T-08 | 终端核心 | Termux v0.118.3（terminal-emulator/view，Apache-2.0） | 成熟实现，重写不现实；保留第三方声明 |
| T-09 | 应用包名 | `com.debdroid.app`（保持） | 与旧版一致（签名不同，旧版需卸载重装） |
| T-10 | 签名 | **全新 keystore**（PKCS12，别名 debdroid） | 用户决定不抢救旧私钥；keystore 本机备份于 ~/.dsh/keystores/debdroid/，base64 存 GitHub Secrets |
| T-11 | 版本号 | versionName 手工维护；versionCode 由 CI `$GITHUB_RUN_NUMBER` 注入 | 每次构建唯一递增 |
| T-12 | 发布 | GitHub Actions 云编译，成功即发 Release 附 APK | 本地不装 SDK；手机从 releases/latest 覆盖安装 |

## 4. 功能需求（FR）

编号规则：`FR-<域><序号>`，域：T=终端，S=会话，F=文件，E=编辑器，H=SSH，K=保活，W=向导，C=系统设置。
每条 FR 含 EARS 描述 + 可测验收标准。优先级：**P0**=必须（v2.0.0 全部 P0），P1=重要，P2=可选。

### 4.1 安装与首次启动（向导）

**FR-W1【事件】当用户首次启动且 rootfs 未安装时，系统应进入安装向导。**
- 验收：全新安装首次打开显示向导页；rootfs 已安装时直接进终端页；设置中"恢复出厂"后回到向导。
- P0

**FR-W2【事件】当用户在向导点击「安装 Debian」时，系统应在后台解压内置 rootfs.tar.xz 并显示进度。**
- 验收：解压过程 UI 不冻结；进度百分比单调递增；步骤文案（解压/配置/启动环境）随阶段切换；失败时显示错误并可重试，不闪退。
- P0

**FR-W3【状态】在向导完成安装后，系统应写入 proot 启动环境并进入终端页。**
- 验收：解压完成后自动进入终端；首次进入自动创建第一个会话。
- P0

**FR-W4【条件】在中文系统语言且用户未手动选择镜像源时，首次安装完成应默认使用清华 TUNA 镜像。**
- 验收：zh 语言环境安装完成 → apt 源为 TUNA；非 zh 环境 → 官方源；用户已手动选择 → 尊重用户选择。
- P1

### 4.2 终端核心

**FR-T1【事件】当用户打开会话时，系统应以 proot 启动 Debian bash，并应用 v2 标准 proot 配置（见 6.4）。**
- 验收：会话内可执行 `/bin/bash --login`；`uname -a` 显示 Debian；proot 参数含 `-l -L --kill-on-exit`；环境含 `PROOT_F2FS_WORKAROUND=1`；不设置 `PROOT_NO_SECCOMP`。
- P0

**FR-T2【状态】在终端可见的状态下，系统应实时渲染终端输出（≥60fps 输入回显无感知延迟）。**
- 验收：输入字符回显无 ~500ms 延迟（v1.0.8 修复回归）；滚动查看历史输出；捏合缩放字号。
- P0

**FR-T3【状态】在终端可见的状态下，系统应提供扩展键面板（3 排 29 键，含 ESC/TAB/CTRL/ALT/方向键），支持长按连发与震动反馈。**
- 验收：29 键布局与模拟页一致；长按连发；轻量震动；CTRL/ALT 组合键生效（如 Ctrl+C 中断前台进程）。
- P0

**FR-T4【状态】在终端可见的状态下，系统应按所选配色方案渲染（8 套：Dracula/Nord/Gruvbox/Tokyo Night/Solarized/One Dark/Monokai/Catppuccin），并支持 Nerd Font 开关。**
- 验收：8 套配色可切换且立即生效；Nerd Font 开关生效（等宽图标字体）；默认 Dracula。
- P0

**FR-T5【状态】在终端有活动输出的状态下，系统应保持屏幕唤醒直至会话空闲（由唤醒锁设置控制）。**
- 验收：开启唤醒锁时息屏不中断任务；关闭时恢复正常息屏。安装完成后不得常亮（v1.0.17 回归防护）。
- P1

### 4.3 会话管理

**FR-S1【事件】当用户点击新建会话时，系统应创建新会话（proot 进程 + 终端），且多会话互不干扰。**
- 验收：可同时存在 ≥2 个会话；切换会话保留各自屏幕状态；关闭一个不影响其他。
- P0

**FR-S2【状态】在有 ≥1 个会话的状态下，用户可从抽屉选择/关闭会话，关闭有确认（避免误触）。**
- 验收：抽屉列出全部会话（名称 + tmux 徽标 + 活跃指示）；关闭需二次确认；全部关闭可用。
- P0

**FR-S3【条件】在启用 tmux 保持且启动命令为默认值时，新会话应执行 `tmux new -A -s main`。**
- 验收：默认配置下新会话进入 tmux 会话 main；自定义启动命令时原样执行（不包裹 tmux）；设置关闭 tmux 时用默认 bash。
- P0

**FR-S4【事件】当系统进程被回收后服务自动重启时，系统应按设置自动恢复会话。**
- 验收：开启"自动恢复会话"时，重启后自动重开之前的会话；关闭时不自动开。恢复路径与手动创建不产生重复会话（单飞）。
- P0

**FR-S5【条件】在会话启动失败时，系统应以 Toast 提示具体失败原因，且不闪退。**
- 验收：rootfs 缺失/proot 解包失败等场景显示中文错误提示；App 进程存活。
- P0

### 4.4 文件管理器

**FR-F1【状态】在文件管理页的状态下，系统应显示 Linux（Debian rootfs）与手机存储双栏，两栏可独立浏览。**
- 验收：左右栏各显示各自根路径；点击目录进入；返回键逐级回退；双栏独立（L 进 A 目录不影响 R）。
- P0

**FR-F2【状态】在文件管理页的状态下，系统应支持排序（名称↑↓/大小/时间）与书签收藏。**
- 验收：排序切换即时生效；书签可添加/删除/点击跳转；路径可原位编辑、显示上级入口。
- P0

**FR-F3【事件】当用户长按/勾选文件进入多选模式时，系统应提供批操作：全选/反选/按类型选、复制/移动→对侧、删除（带不可撤销确认）。**
- 验收：多选模式操作栏出现；复制/移动在后台线程执行不卡 UI；删除二次确认文案含"不可撤销"；大文件夹操作有进度反馈。
- P0

**FR-F4【状态】在文件列表可见的状态下，系统应显示真实 POSIX 权限串（Os.lstat），目录/文件类型图标细分（APK/视频/音频/文本/目录/链接）。**
- 验收：`drwxr-xr-x` 风格权限串与实际一致；图标按类型区分。
- P0

**FR-F5【事件】当用户点击文本类文件时，系统应打开内置编辑器。**
- 验收：.py/.md/.sh/.txt/.json/.conf 等可编辑；二进制文件不进入编辑器。
- P0

### 4.5 文本编辑器

**FR-E1【状态】在编辑器打开的状态下，系统应显示行号栏并与内容同步滚动。**
- 验收：行号正确；滚动同步无错位；万行文件编辑流畅（Canvas 绘制）。
- P0

**FR-E2【事件】当用户执行查找时，系统应支持查找/替换（计数、跳转、全部替换）。**
- 验收：查找高亮全部匹配并显示计数；替换支持单个/全部；无匹配有提示。
- P0

**FR-E3【状态】在编辑器有未保存修改的状态下，系统应显示脏标记并在离开时拦截确认。**
- 验收：修改后标题栏出现"未保存"；返回/关闭弹确认（取消留在编辑器）；保存后脏标记消失。
- P0

**FR-E4【状态】在编辑器打开的状态下，系统应支持撤销/重做（≥100 步）、跳转到行、自动换行开关、字号调节、只读模式切换、符号快捷条、Ln/Col 状态栏。**
- 验收：撤销/重做正确；只读时不可编辑；各功能开关即时生效。
- P0

### 4.6 SSH 服务器

**FR-H1【事件】当用户在设置启用 SSH 时，系统应直接启动 rootfs 内预装的 openssh-server（无需联网安装）。**
- 验收：启用后 sshd 进程运行；局域网 `ssh root@<手机IP> -p <port>` 可登录；rootfs 内置 openssh-server（镜像构建时预装）。
- P0

**FR-H2【状态】在 SSH 启用的状态下，系统应显示真实运行状态与失败原因。**
- 验收：状态区显示监听地址与端口；端口占用/配置错误等显示 sshd 实际 stderr；停止后端口释放可立即重启（等待 ≤3s）。
- P0

**FR-H3【状态】在设置页的状态下，系统应支持 SSH 配置：端口（1024–65535）、监听地址（仅局域网/全部接口）、密码登录、公钥授权、开机自启。**
- 验收：修改端口后重启生效；密码为空时禁用密码登录；公钥支持多把；快速开关不产生并发竞态（按钮 busy 禁用）。
- P0

### 4.7 保活

**FR-K1【状态】在启用保活的状态下，系统应以前台服务维持进程（常驻通知 + 防回收）。**
- 验收：前台服务通知可见；切换 App/锁屏后会话存活。
- P0

**FR-K2【状态】在保活设置的状态下，系统应提供独立开关：前台服务 / 唤醒锁 / 电池优化白名单 / 开机自启 / 自动恢复会话，且各自独立生效。**
- 验收：每项开关独立持久化；关闭前台服务则不再常驻通知；开机自启需 RECEIVE_BOOT_COMPLETED 权限。
- P0

**FR-K3【事件】当用户首次需要电池白名单时，系统应引导打开系统"忽略电池优化"页面（REQUEST_IGNORE_BATTERY_OPTIMIZATIONS）。**
- 验收：点击可跳系统设置页；用户拒绝不崩溃。
- P1

### 4.8 系统设置

**FR-C1【状态】在设置页的状态下，系统应支持 apt 镜像源切换（官方/清华/中科大/阿里/腾讯），切换后重写 sources.list 并即时生效。**
- 验收：5 个镜像可选；切换后 `apt update` 使用新源；镜像 URL 完整（含 debian-security，v1.0.24 修复不回退）。
- P0

**FR-C2【状态】在设置页的状态下，系统应支持自定义 DNS（写入 rootfs resolv.conf）与恢复出厂（离线重解压内置镜像）。**
- 验收：DNS 生效（resolv.conf 正确）；恢复出厂停止会话/SSH 后回向导，重装后可再次进入终端。
- P0

**FR-C3【事件】当设置变更时，系统应通过 DataStore 持久化并在重启后保留。**
- 验收：修改任意设置 → 杀进程重启 → 设置保留。
- P0

**FR-C4【状态】在设置页的状态下，系统应显示应用版本号（versionName + 构建号）。**
- 验收：版本号与 CI 构建一致。
- P1

### 4.9 质量与工程（门禁）

**FR-Q1【常态】系统应附带单元测试，CI 中测试失败即阻断 Release。**
- 验收：`./gradlew testReleaseUnitTest` 全绿才允许发 Release；新增核心逻辑（proot 参数、会话、设置、解析器）必须有测试。
- P0

**FR-Q2【事件】当版本发布时，系统应同步更新 CHANGELOG.md（含修复/新增/变更/移除小节）。**
- 验收：每次 tag 对应 CHANGELOG 条目；内容与 git log 一致。
- P0

**FR-Q3【常态】系统构建应可复现：rootfs/proot 资产带 SHA256 校验，CI 缓存命中不重复下载。**
- 验收：fetch 脚本校验和验证；失败不产出错误资产。
- P0

## 5. 非功能需求（NFR）

### 5.1 性能（P-*）
| # | 需求 | 指标 |
|---|---|---|
| P-01 | 首次安装（解压内置 rootfs） | ≤3 分钟（典型设备），进度可见 |
| P-02 | 会话启动（proot 拉起） | ≤3s（rootfs 已解压后） |
| P-03 | 终端输入回显 | 无感知延迟（<100ms），不依赖光标闪烁重绘 |
| P-04 | 大目录（>1000 项）浏览 | 列表滚动流畅，勾选无卡顿（异步加载） |
| P-05 | 万行文件编辑 | 行号栏 Canvas 绘制，编辑/滚动流畅 |
| P-06 | 复制/移动大文件夹 | 后台线程执行，UI 不冻结，有进度反馈 |
| P-07 | 安装进度回调 | 节流（≤100 次重组/秒），不刷爆 UI |
| P-08 | APK 体积 | rootfs+proot 资产压缩打包，目标 ≤120MB（arm64 单架构） |

### 5.2 安全（S-*）
| # | 需求 |
|---|---|
| S-01 | SSH 默认仅监听局域网；密码/公钥由用户显式设置；无默认弱口令 |
| S-02 | 明文 HTTP 政策收紧：App 内网络请求仅允许必要域名（apt 镜像、LXC 下载在 CI 侧） |
| S-03 | 不申请多余权限；存储读写仅限应用可见目录（requestLegacyExternalStorage 范围） |
| S-04 | keystore 私钥不进入仓库；仅以 base64 存 GitHub Secrets；本机备份权限 600 |
| S-05 | rootfs 镜像下载在 CI 侧完成并 SHA256 校验，不向最终用户下发可执行负载 |

### 5.3 兼容性（C-*）
| # | 需求 |
|---|---|
| C-01 | minSdk 26 至最新（compileSdk 36）均可安装运行 |
| C-02 | 仅 arm64-v8a；其他 ABI 设备安装时提示架构不匹配 |
| C-03 | 深浅主题跟随系统；中英文界面文案齐全 |
| C-04 | 侧载安装（非 Play 商店）场景正常（"为旧版 Android 设计"提示为预期行为，同 Termux） |

### 5.4 可靠性（R-*）
| # | 需求 |
|---|---|
| R-01 | 进程被系统回收后：服务自启、会话按设置恢复、SSH 状态恢复 |
| R-02 | 任何后台异常（解压/apt/SSH/proot）不得导致闪退；一律转 Toast/状态提示 |
| R-03 | 会话创建与恢复路径无竞态（单飞 ensureSession）；无死锁（锁不可重入嵌套） |
| R-04 | SSH 启停快速连点不产生并发竞态（busy 态禁用） |
| R-05 | 终端会话进程句柄跨线程可见性正确（volatile/同步） |

### 5.5 无障碍（A-*）
| # | 需求 |
|---|---|
| A-01 | 主要图标按钮（抽屉/菜单/扩展键）带 contentDescription |
| A-02 | 触控目标 ≥44dp；正文字号 ≥14sp |
| A-03 | 颜色对比度满足 WCAG AA（深色主题下正文 ≥4.5:1） |

## 6. 界面规格（元素级）

> 每屏列出：布局要点、元素表（类型/状态/行为）、状态覆盖（空/加载/错误）。

### 6.1 安装向导（WizardScreen）
- 布局：垂直居中——旋涡 Logo（96dp）→ 标题 DebDroid → 副标题 → 步骤指示（3 点）→ 进度卡片 → 主按钮。
- 元素：
  | 元素 | 类型 | 状态 | 行为 |
  |---|---|---|---|
  | 旋涡 Logo | SVG | 静态 | — |
  | 标题 | Text(headline, mono) | — | — |
  | 副标题 | Text(caption) | — | "在手机上运行完整的 Debian 13 · 免 root" |
  | 步骤指示 | 3 dots | done/now/pending | 随安装阶段推进 |
  | 进度卡片 | Card | 安装中：步骤文案+百分比+进度条 | 后台解压回调 |
  | 主按钮 | Button(filled, block) | 空闲"安装 Debian" / 完成后"进入终端 ▸" | 触发安装 / 进终端页 |

- 状态覆盖：
  - 加载：进度百分比 0→100，步骤文案切换

  - 成功：步骤全 done，按钮变"进入终端"

  | ☰ 按钮 | IconButton | — | 开抽屉 |

  | ⋮ 菜单 | IconButton | — | 菜单：新建会话/配色/… |
  | 终端区 | TerminalView | 渲染终端 | 输入输出实时 |

### 6.3 文件管理器（FileBrowserScreen）
- 布局：顶栏（← + 路径标题 + ⋮）→ 双栏（各含 pane-header + 文件列表）→ 多选时底部批操作栏。
- 元素：
  | 元素 | 类型 | 状态 | 行为 |
  |---|---|---|---|
  | 路径标题 | Text(mono) | `debian:/root ⇄ 手机:Download` | 点击可原位编辑 |
  | ⋮ 菜单 | IconButton | — | 排序（名称↑↓/大小/时间）、书签管理 |
  | L/R pane | 文件列表 | 每项：图标+名称+大小+权限 | 点击进目录/打开文件；长按多选 |
  | 批操作栏 | 底部栏 | 仅多选时显示 | 复制→对侧/移动/删除(确认)/全选 |
  | 排序 chip | ChipRow | 单选 | 即时重排 |
- 状态覆盖：
  - 空：空目录 → 空态"此文件夹为空"
  - 加载：大目录异步加载中（行内骨架）
  - 错误：权限拒绝/路径不存在 → 提示
  - 操作反馈：复制/移动/删除 → snackbar 结果；删除确认弹窗（不可撤销）

### 6.4 文本编辑器（TextEditorScreen）
- 布局：顶栏（← + 文件名(+未保存徽标) + 💾 + ⋮）→ 行号栏 + 内容区 → 符号快捷条 → 状态栏（Ln/Col）。
- 元素：
  | 元素 | 类型 | 状态 | 行为 |
  |---|---|---|---|
  | ← | IconButton | 脏时弹确认 | 回文件管理器 |
  | 文件名 | Text(mono) + 徽标 | 干净/脏 | — |
  | 💾 | IconButton | — | 保存（写回原路径） |
  | ⋮ | IconButton | — | 菜单：查找/跳转行/自动换行/字号 |
  | 行号栏 | Canvas | 同步滚动 | — |
  | 内容区 | 可编辑文本 | 只读/可写 | 编辑 |
  | 符号条 | 7 键 | — | 🔒只读 🔍查找 ↩撤销 ↪重做 ⤵跳行 ⏎换行 A+字号 |
  | 状态栏 | Text(caption) | — | Ln/Col · 编码 · 脏标记 |
- 状态覆盖：

  - 只读：🔒 激活，不可编辑

### 6.5 设置页（SettingsScreen）
- 布局：顶栏（← + "设置"）→ 分组列表：外观/终端/SSH/保活/系统。
- 外观组：
  | 元素 | 类型 | 行为 |
  |---|---|---|
  | 主题模式 | 列表项(值) | 跟随系统/深色/浅色 |
  | 终端配色 | 8 色块网格 | 单选即生效 |
  | Nerd Font | 开关 | — |
  | 终端字号 | 列表项(值) | 调节 8–32 |
- 终端组：启动命令（编辑）、初始目录（编辑）、tmux 保持（开关）
- SSH 组：启用（开关）、状态行（运行中·地址·端口）、端口、监听地址、密码登录、公钥授权、开机自启（开关）
- 保活组：前台服务/唤醒锁/电池优化白名单/开机自启/自动恢复会话（5 开关）
- 系统组：apt 镜像源（5 选 1 单选列表）、自定义 DNS、恢复出厂（红色入口 + 确认）、版本号
- 状态覆盖：
  - SSH：未安装/安装中/运行中/失败(原因)
  - 恢复出厂：确认弹窗 → 回向导
  - 保存：snackbar"已保存"

## 9. 风险与缓解

| # | 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|---|
| R-01 | proot 在部分 ROM/内核上行为异常（f2fs 等） | 中 | 高 | 内置 v1.x 全部经验参数（F2FS workaround、/tmp 与 npm 绑定）；保持可配置 |
| R-02 | targetSdk 28 触发 Play 政策限制 | 中 | 低 | 定位为侧载工具（同 Termux），README 说明 |
| R-03 | rootfs 体积撑大 APK | 低 | 中 | xz 压缩；arm64 单架构；体积目标 ≤120MB |
| R-04 | 全新签名导致旧版用户无法覆盖安装 | 必然 | 中 | 决策已确认（从零开始）；README 注明卸载旧版 |
| R-05 | 无本地 SDK，编译错误只能靠 CI 发现 | 中 | 高 | 关键逻辑配套单元测试；CI 全量编译 + 测试门禁；语法检查本地先行 |
| R-06 | SSH 被系统网络策略阻断（后台限制） | 中 | 中 | 前台服务保活；文档说明 |
